# ZARIAH Studio Dynamic Product SEO

## What is included
- Product pages are server-rendered by `product-seo.php` using the published product record in Supabase.
- SEO title and description are auto-generated by a database trigger whenever a product is created or its name/description changes.
- Existing manually entered SEO values are retained as overrides.
- Product JSON-LD, canonical URL, Open Graph and Twitter metadata are generated from the live product record.
- `sitemap.php` returns the currently published products from Supabase.
- `robots.txt` points crawlers to the dynamic sitemap.
- `products/.htaccess` routes product URLs to the server-rendered PHP page.

## cPanel deployment
1. Pull the latest `main` branch into the website document root.
2. Confirm PHP 7.4+ and Apache `mod_rewrite` are enabled (typical cPanel defaults).
3. Confirm PHP cURL is enabled; the product renderer also has a stream-wrapper fallback.
4. Confirm the root `.htaccess` is deployed. It routes `/products/<slug>/` to `product-seo.php` before existing static product folders are resolved.
5. Open `https://www.zariahstudio.com/products/essence01/` and confirm it loads with the existing product layout.
6. Open `https://www.zariahstudio.com/sitemap.php` and confirm it returns XML.
7. Test an unpublished/non-existent slug; it should return HTTP 404 and noindex.

The production Supabase migration was applied separately to project `keuqvqnhxlpsglsjfopd`. The SQL is retained under `database/migrations/` for source control.

## Important
- Do not add a Supabase service-role key to this repository. The PHP files use only the public publishable key.
- Do not remove the existing product CSS, cart, gallery, WhatsApp or related-product scripts.
